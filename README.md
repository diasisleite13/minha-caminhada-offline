
# Minha Caminhada Offline 🚶

Aplicativo de caminhada para Android com GPS e histórico local.

## Funcionalidades

- Rastreamento GPS.
- Cálculo de distância em quilômetros.
- Cronômetro.
- Velocidade média.
- Ritmo médio.
- Histórico de caminhadas.
- Exportação dos dados em JSON.
- Armazenamento local.
- Interface instalável no Android.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Leaflet
- OpenStreetMap
- Geolocation API
- Service Worker

## Instalação no GitHub Pages

1. Crie o repositório minha-caminhada-offline.
2. Envie todos os arquivos para a raiz.
3. Acesse Settings.
4. Entre em Pages.
5. Em Build and deployment, selecione Deploy from a branch.
6. Escolha a branch main e a pasta / (root).
7. Clique em Save.

## Uso no Android

1. Abra o endereço HTTPS do GitHub Pages.
2. Permita o acesso à localização.
3. Escolha Adicionar à tela inicial no Chrome.
4. Abra o aplicativo instalado.
5. Inicie sua caminhada.

## Privacidade

Os registros são armazenados localmente no navegador.
Não existe envio automático de localização para um servidor.

## Observações

O GPS necessita de permissão de localização.
O mapa online utiliza OpenStreetMap.
Os mapas não são baixados automaticamente para uso offline.
O rastreamento contínuo com a tela bloqueada não é garantido em navegadores Android.
